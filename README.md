# 火羽ひのめ 千舰史料 · 直播回放检索

火羽ひのめ 2022 年 10 月 10 日至 13 日四场 B 站直播的回放检索站。双语字幕、弹幕、醒目留言（SC）和上舰记录放在同一条时间线上，可以搜索、筛选，并跟着视频同步滚动。

- 站点：<https://re-summer75.github.io/hinome-archive/>
- 视频：[BV1v1HN6YEyV](https://www.bilibili.com/video/BV1v1HN6YEyV)（四个分 P）

## 功能

- **点任意一行**（字幕、弹幕或 SC），视频从那一行前两秒开始播放，其余几栏跳到同一时间。
- **搜索**同时查字幕（日文和中文）、弹幕、SC 和观众名，结果分别列在各栏。
- **只看某位观众**：弹幕栏和 SC 栏只剩这位观众的内容；点「提到 TA」只看念到 TA 名字的字幕。
- **时间线**：弹幕热度、SC、舰长每满 100 的时刻，以及搜索命中的位置都标在进度条上；鼠标停在上面能看到那一刻的时间、舰长数和字幕。
- **同步**：视频在本页播放，三栏按它的真实播放位置逐帧跟随，可以倍速。取不到流时退回 B 站外链播放器，改为估算同步。
- **分享**：每行都能复制带时间点的链接，别人打开就跳到同一处。

快捷键：空格 播放/暂停，J / L 后退/前进 10 秒，`/` 搜索，Esc 清空。

## 数据

| 内容 | 来源 |
|---|---|
| 字幕 | 三个语音识别模型听写，Gemini 整理翻译，再经二审、三审，与视频里的字幕一致。难免有误，请保持怀疑 |
| 弹幕、SC、上舰、礼物 | 录播时同步保存的原始记录。弹幕原样收录，礼物只列付费礼物 |
| 头像 | 录播里 SC 和礼物记录附带的头像（当时的头像）；只发过弹幕的观众显示名字的首字 |
| 北京时间 | 按弹幕发送时间推算的直播实况时间，仅供参考 |
| 舰长数 | 第三方统计站 vtbs.moe 的历史记录，两次记录之间按上舰消息逐个累加，仅供参考 |

## 目录

```
site/
  index.html   页面
  app.js       检索、筛选、时间线、播放同步
  stream.js    页内播放
  style.css    样式
  data/        每个分 P 的字幕、弹幕、SC 等（p1–p4.json），以及分 P 列表（videos.json）
  assets/      装饰图片、头像拼图、标题字体子集
```

本地预览：

```bash
python -m http.server 8770 --directory site
```

然后打开 <http://127.0.0.1:8770/>。
